# Task 1: Student Grade Tracker

## Description
A console-based Java application to store student grades and generate reports. It supports adding students, adding more grades, viewing an individual report, and viewing a class summary.

## Features
- Stores multiple students using `ArrayList`.
- Stores multiple grades for each student.
- Calculates average, highest, and lowest grades.
- Validates grades from 0 to 100.
- Uses object-oriented programming with a `Student` class.

## Requirements
- Java JDK 8 or later.

## How to run
Open a terminal in this folder and run:

```bash
javac StudentGradeTracker.java
java StudentGradeTracker
```

## Menu
1. Add student and grades
2. Add grade to existing student
3. View student report
4. View class summary
5. Exit

## Note
This beginner-friendly version stores data in memory while the program is running. Records reset when the application is closed.
